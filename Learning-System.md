# Learning System

## Purpose
This repository is the persistent source of truth for the user's long-term learning roadmaps.

## Global Learning Protocol

### Before every learning session
1. Identify the subject being learned.
2. Read that subject's `Roadmap.md`.
3. Read that subject's `Progress.md`.
4. Read that subject's `Rules.md`.
5. Determine the exact current topic from `Progress.md`.
6. Continue from that topic. Do not skip ahead or silently reorder topics.

### During learning
1. Teach one topic at a time.
2. Explain clearly and progressively, using simple examples where useful.
3. Build deep understanding before moving on: what it is, why it exists, how it works, when to use it, trade-offs, common mistakes, and practical examples when relevant.
4. Check understanding before marking a topic complete.

### On topic completion
1. Update the appropriate subject `Progress.md` immediately.
2. Record the completed topic and the next topic.
3. Preserve any important notes, weak areas, or pending practice.
4. Verify the saved progress before moving to the next topic.
5. The chat conversation is not the authoritative progress record; the GitHub progress file is.

### Continuation rule
When starting a new chat, use the repository files as the source of truth and continue from the saved current topic. Do not rely on memory of a long previous conversation when the repository contains the state.
